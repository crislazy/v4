## So, what happened?
So, basically , I ~~have~~ had a Raspberry Pi 4 with 4 GB of RAM running 24/7 and hosting a few websites, bots and Home Assistant and some other stuff I forgot. One day, I decided to install Coolify on it and for a while it worked :)

2-3 days later, after running fine, I got notified that my containers were down and when I SSHed to check, most of the commands wouldn't work in the terminal so I had to manually unplug the Raspberry Pi.

After 2-3 reboots, it kinda worked, but some things were broken and I had to delete coolify and to power off the Pi until I will fix it. But probably I should buy a new SD card as the one I'm using isn't designed to run 24/7(I kinda knew that for months because the SD card corrupted a few times before this happened... :/)

## Uhh, so what now?
Well, because I can't really trust the SD card that much to not corrupt, I should wait until I get a new one made to run 24/7.

And for the stuff I need to host somewhere, I will find other places to host on, like [Hack Club Nest](https://hackclub.app) or maybe get an actual VPS.
